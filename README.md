## What this is

*Security 51* puts you on a checkpoint desk deep inside an Area 51 bunker, with an elevator behind you that descends miles into laboratories nobody will describe to you. Staff arrive with documents, passes and verbal orders. You check names, positions, clearance levels, schedules and headcounts, and you watch for the things paperwork can't cover — a wrong answer, slurred speech, a document that looks a little too perfect. Then you decide who goes down, and who absolutely must not come back up.

It's *Papers, Please* with SCP paranoia, from Alawar — the studio behind Beholder and Do Not Feed the Monkeys, who have been making games about bureaucratic dread for a decade.

Which makes a trainer for it an awkward object, and worth being upfront about. **The verification work is the entire game.** An option that circles every discrepancy for you doesn't make Security 51 easier — it makes Security 51 not happen. You'd be left clicking a stamp on prompts.

So this trainer is built around that line. Most of what's here removes **friction**: the shift clock, the credit squeeze, tools locked behind progression, consequences arriving three shifts after you forgot the decision. A smaller set removes **the inspection itself**, and those are tagged.

## Bypass and spoiler tags

Two tags appear next to option names in the menu.

**`bypass`** — this option does the checking for you. Highlight document errors, reveal what's standing there, highlight behavioural tells, show clearance level directly, reveal the roster, auto-stamp the obvious cases. All off by default.

If you turn these on for a first playthrough, you'll finish the game without having played it. They're here for people replaying to reach a different ending, or grinding a late shift they've already solved and lost to one misread digit.

**`spoiler`** — this option shows you story content early. Preview the consequence, reveal what's below, reveal choice outcomes, unlock all endings, ending gallery. Also off by default.

Security 51 has multiple endings and delayed consequences that only surface several shifts later. That structure is the reason to replay it. Seeing the map before you walk it takes that away.

Everything untagged is friction removal — credits, fines, timers, tool unlocks, readability. None of it touches the actual inspecting.

## Installation

1. **Download** the latest archive from the [Releases page](https://github.com/RapidsLordConnector/Security-51-Trainer/releases/latest).
2. **Unblock it** — right-click the `.zip`, choose Properties, tick *Unblock*, then Apply. Windows quarantines downloaded archives and the trainer won't attach otherwise.
3. **Extract** anywhere outside `Program Files`.
4. **Launch the game first** and start a shift, so the process exists.
5. **Run the trainer as administrator.** The header should read `attached` with your current shift number.
6. **Press `Insert`.**

Save data typically sits under `%USERPROFILE%\AppData\LocalLow` in the developer's folder — check your install for the exact path. Turn off Steam Cloud while you experiment so a bad local write doesn't sync upward.

## How to use the mod menu

Pick a tab on the left, flip what you need on the right. Sliders update live.

A few setups worth knowing:

- **Read properly, cheat nothing:** `Freeze the shift clock` + `Detail zoom 6x` + `High-contrast document mode` + `Interface scale 130%`. Nothing tagged. You still find every discrepancy yourself, you just get to actually look at the documents.
- **Financial pressure off:** `Infinite credits` + `No fines or deductions`. The inspection stays intact; the survival-budget layer goes away.
- **All the tools, from shift one:** `Unlock all inspection tools` + `No tool cooldowns` + `Instant blood analysis`. Early shifts get more interesting rather than easier.
- **Chasing a different ending:** `Replay any shift` + `Skip dialogue` + `Auto-stamp the obvious cases`. You've done the work; now you want the branch.
- **Harder, not easier:** `Protocol level: Lockdown` + `Personnel quota 40` + `Shift length 0.6x`.

## Troubleshooting

**Trainer says the process wasn't found.** The game has to be running with a shift loaded. Launch Security 51, start a shift, then start the trainer.

**Nothing happens when I press Insert.** Another overlay is eating the key. Steam's overlay, Discord and RTSS are the usual suspects. Rebind under **Trainer → Menu key**.

**Inspection options do nothing at the desk.** They bind when a visitor is actually at the window. Call the next person up, then toggle.

**Highlighting shows errors that aren't errors.** The highlighter reads the game's own validation state, and some checks resolve only after you use a specific tool. A blood-test discrepancy won't show until the blood test is run.

**A shift ended in a state that makes no sense.** Turning `bypass` options on and off mid-shift can leave the validation state inconsistent. Reload the shift.

**My save broke after an update.** Progress-writing options can be invalidated by a patch. Restore a rolling backup from before the update.

**Windows Defender flagged it.** Trainers read and write another process's memory, which is what a lot of malware also does, so heuristic scanners flag them on principle. Add an exclusion if you're comfortable with that — and if you'd rather not, don't. That's a reasonable call.

**I only have the demo.** The demo and the old playtest are separate app IDs and aren't supported.

## FAQ

### Will I get banned for using cheats in Security 51?

No. It's a single-player game with no anti-cheat and no multiplayer, so there's nothing to be banned from. Achievements unlock locally unless you block them in the Trainer tab.

### Does the trainer spoil the story?

Only if you turn on a `spoiler`-tagged option, and all of them are off by default. Security 51 has multiple endings and consequences that surface several shifts after the decision — the tagged options show you that structure early. Everything else leaves the narrative exactly as written.

### Does it highlight document errors like a Papers, Please cheat?

It can, but that option is tagged `bypass` and ships off. Finding the discrepancy is the game; the highlighter is for replays, not first playthroughs.

### Can I get infinite money in Security 51?

Yes, in the Career tab, along with a salary multiplier and no fines or deductions.

### How do I stop the shift timer?

**Freeze the shift clock** in the Shift tab, or use the shift length slider to stretch the day instead. Both leave the inspection work untouched.

### Can I make the documents easier to read?

Yes — **Detail zoom range**, **Interface scale** and **High-contrast document mode**. None of them reveal anything; they just make pixel-art fine print legible on a large monitor.

### Can I unlock all the endings?

There's an option for it in the Story tab, tagged `spoiler`. **Replay any shift** is usually the better route — it lets you chase a branch you missed without restarting the whole run.

### Does it work on the demo?

No. The demo and the earlier playtest build both run on separate app IDs.

### Does it work on Steam Deck or Linux?

No. Windows only. Proton changes how the game's memory is laid out.

### How do I turn everything off?

Press `End`.
